# New Start-app website-header concepts

These replace the earlier generic arrow/window/stack choice sheet. None is selected. Website header only, no application/package icon work.

All three were drawn locally as SVG paths for this review, without an external icon library or downloaded asset. They combine an S route with the product idea of grouping items and opening them together. Local authorship is not proof of global uniqueness; no trademark or similarity search was performed.

1. S route: an S-shaped launch path, two collected-item dots and an outgoing arrow. The S is the main reading; the dots suggest items collected into one route.
2. S workspace: a bracket holds two small items alongside an S-shaped launch path. A more literal workspace/grouping idea.
3. S link: three input strokes meet an S route beside an open frame. A more technical, connected-items direction.

Each uses a custom 32-unit grid, one stroke weight, and the selected cobalt palette. The existing repository arrow remains the provisional draft header until one new concept is chosen. Replace only the decorative header SVG across both Hebrew pages and locale pages after selection; preserve the accessible home-link name. The prior generic sheet is superseded.

Prior option provenance: the arrow reused the base repository header geometry; the window and stack were locally drawn common motifs, not downloaded assets. No originality or uniqueness claim was made for those common symbols.
